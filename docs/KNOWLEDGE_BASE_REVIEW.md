> These 41 cards are draft first-aid guidance written in our own words for a student project. They are not copied from any manual.
> The "Source" column names the public guidance each card follows in spirit. It is not a quote and not a page citation.
> **A qualified medical professional must review every card before MediGo is used with real patients.**

Generated from `src/data/seed/emergencyCards.ts` (knowledge base version 5, see `KB_VERSION` in `src/data/seed/firstRun.ts`).
Regenerate this sheet if the cards change.

## How the cards are used

- **Online**: the top 3 matching cards are sent to the model as REFERENCE. The model rates each report itself.
- **Offline**: the best matching card is shown directly with its *default* severity and steps. These defaults are the only rating the user gets offline, so they matter most.
- "Default severity" is `severityColor / severityLevel`. "Seek facility" is `seekFacility`.

## Please check first (highest risk)

1. **New card: *Choking in a baby*** (card 41, added in v5). Infant back blows and chest thrusts, no abdominal thrusts, no blind finger sweeps. Please check every step.
2. **Doses removed in v5**: *Heart attack* no longer has the aspirin 300 mg step, and *Asthma attack* no longer has puff counts. Both now say "as prescribed". The server prompt also forbids doses. Please confirm the *Heart attack* card is still safe and useful without aspirin advice.
3. **CPR**: *Cardiac arrest* and *Drowning* are adult instructions. There is no infant or child CPR card, and "my baby is not breathing" currently returns *Fever in a baby* first.
4. **Snakebite, Scorpion sting, Pregnancy emergency, Seizure**: high-risk cards with "do not" rules.
5. **Mixed defaults**: YELLOW with HIGH (Animal bite, Seizure, Asthma, Head injury, Chemical burn, Fever in a baby) and RED with MEDIUM (Scorpion sting). Confirm each one is intended.
6. **Offline defaults that may be too low**: Burns (seekFacility No), Hypoglycaemia (YELLOW, seekFacility No), Nosebleed and Minor burn (GREEN).

Cards marked ⚠ in the last column are the ones we are least sure about.
